## 👥 Core Roles

- **Project Manager (PM)** — Coordinates delivery, manages schedule, risk, and communications
- **Product Manager (PdM)** — Defines outcomes, prioritizes backlog, measures success
- **Developer** — Implements features, collaborates on design, maintains quality
- **QA/Testing** — Validates quality, ensures acceptance criteria met
- **Stakeholders** — Provide inputs, approve changes, receive updates

See [Roles and Personas](./octoacme-roles-and-personas.md) for detailed responsibilities.
